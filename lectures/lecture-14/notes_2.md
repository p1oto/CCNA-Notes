# Lecture 14 (Part 2): LAN Switching & VLANs

## 📝 أولاً: ملاحظات هامة (Notes)

• **سويتشات الأكسس (Access Switches):** السويتشات التي تتصل مباشرة بأجهزة المستخدمين (الكمبيوترات). أمثلة حديثة من خط إنتاج سيسكو كاتاليست: (`9100` للوايرلس، و `9200`، و `9300`).

• **سويتشات الكور (Core Switches):** سويتشات رئيسية قوية (بروسيسور ورامات أعلى) تجمع سويتشات الأكسس معاً لربط أقسام الشبكة. أمثلة: (`9400`، و `9500`، و `9600`).

• **مشكلة الـ Broadcast في الشبكات الكبيرة:**
عندما يزيد عدد الأجهزة في نفس الشبكة عن 200 جهاز، تصبح الشبكة عبارة عن نطاق بث واحد ضخم (Broadcast Domain). تكرار رسائل الـ Broadcast (مثل ARP و DHCP) يسبب ضغطاً وااختناقاً (Congestion) وبطئاً شديداً نتيجة الـ Flooding المستمر.

• **الحل - الفيلانات (VLANs):**
تقسيم السويتش الحقيقي الواحد إلى عدة سويتشات افتراضية معزولة تماماً عن بعضها أمنياً وتنظيمياً، مما يقلل نطاق الـ Broadcast ويمنع الـ Flooding العشوائي.

• **المعايير والتفاصيل التقنية للفيلان:**
  - تُبنى على معيار IEEE `802.1Q` (ويُعرف اختصاراً بـ dot1q).
  - رقم الـ VLAN يتكون من 12 بت (12-bit)، مما يسمح بإنشاء من 0 إلى 4095 فيلان.
  - **الفيلان الافتراضية (Native / Default VLAN):** هي `VLAN 1` افتراضياً، وكل بورتات السويتش تأتي تابعة لها من المصنع.

• **أنواع البورتات (Port Modes):**
  - **بورت الأكسس (Access Port):** بورت متصل بجهاز كمبيوتر (End Device) لا يفهم الفيلانات، وتكون البيانات خارجه وداخله بدون علامة (Untagged Frame).
  - **بورت الترانك (Trunk Port):** بورت مُجمع يربط بين سويتش وآخر أو سويتش وراوتر، وينقل بيانات كل الفيلانات عن طريق إضافة علامة تعريفية (VLAN Tag / 802.1Q) لهيدر الفريم (Tagged Frame).

• **طرق ربط الفيلانات (Inter-VLAN Routing):**
بما أن الفيلانات معزولة كلياً عن بعضها، نحتاج إلى جهاز Layer 3 للسماح بمرور حركة البيانات (Unicast) بينها عبر 3 طرق أساسية:
  1. **الطريقة التقليدية (Traditional Routing):** استخدام راوتر بكابل حقيقي مستقل لكل فيلان (مكلفة وتهدر البورتات).
  2. **طريقة الـ ROAS (Router on a Stick):** استخدام كابل ترانك واحد يربط السويتش بالراوتر، وتقسيم بورت الراوتر إلى Sub-interfaces وهمية.
  3. **طريقة الـ L3 Switch (Multilayer Switch):** استخدام سويتش كور يمتلك قدرات توجيه (Routing) من الداخل، وهو الحل الأسرع والأحدث.

## ⚙️ ثانياً: أوامر الإعداد (Configuration Commands)

1. الدخول على مجموعة بورتات دفعة واحدة لتوفير الوقت:
</div>

```bash
Switch(config)# interface range fastEthernet 0/1-4
```

<div dir="rtl" align="right">
2. تحويل نوع البورتات إلى وضع الأكسس (Access):
</div>

```bash
Switch(config-if-range)# switchport mode access
```

<div dir="rtl" align="right">
3. إسناد البورتات إلى فيلان معينة (مثال: الفيلان رقم 2):
</div>

```bash
Switch(config-if-range)# switchport access vlan 2
```

<div dir="rtl" align="right">
4. تحويل بورت السويتش إلى وضع الترانك (Trunk):
</div>

```bash
Switch(config-if)# switchport mode trunk
```
